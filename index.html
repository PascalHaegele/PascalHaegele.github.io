My contribution

A script that procedurally generates the following meshes with adjustable radius and resolution:

  • Plane: a square grid of quads on the xz-plane, with separate vertices for each quad
  • Shared Plane: like the Plane, but neighboring quads share vertices
  • UVSphere: uses the Shared Plane as a base, arranging vertices in circles around the center
  • CubeSphere: a cube using a Shared Plane for each side, normalizing the position of each vertex so all are the same distance from the center
  • Torus: a UVSphere that is pulled apart making a hole in the center, and arranging the vertices in a ring around the radius circle

Three Shaders which can be applied to the generated Meshes for different effects:

  • Waves: displaces vertices along their normals to create a wave-like pattern.
  • Ripple: like Waves, but with a ripple pattern, frequency and displacement are adjustable for both shaders.
  • Dissolve: cuts out part of the mesh, creating a colored edge shaped by noise.

Game Prototype: Gothica Solaris

View on GitHub ↗

Gothica Solaris is a first-person roguelite dungeon crawler set in a dark Victorian world where reality is collapsing under the influence of a forbidden Book. Players control Victor, a bounty hunter searching for a missing loved one while exploring corrupted realms.

Its risk-versus-reward system centers on an Insanity Meter: rising Insanity strengthens enemies and destabilizes the environment, but can reveal hidden paths, events, and rewards. Players decide whether to keep exploring or extract safely, collecting Pages and currencies to unlock permanent upgrades in the Mirror Hub. Weapons, Page combinations, Socket upgrades, and abilities support varied builds and replayability.
